# Technical documentation translation policy

Canonical policy language: English. Revision: 9. Updated: 2026-10-28. The Spanish policy is included below.

New engineering documentation uses English as its canonical text, with a synchronized Spanish counterpart. Code, comments, symbols and API contract keys remain English. Each paired document records its revision, update date and a link to the other language. A technical change must update both texts in the same reviewed change, or explicitly identify the untranslated portion; a stale translation must not silently claim synchronization.

`README.md` is an English entry point with direct Spanish guide links. Original user requests, scientific records, historical decisions, bibliography/source logs and progress/acceptance ledgers retain their original language and dates. These are traceability records; translating them must not replace, reinterpret or count the same evidence again. Machine-readable source fields and bibliographic titles retain their source values.

## Finite historical translation backlog

1. The Phase IV candidate annex is a new protocol reading aid, not a literal translation of all H-00–H-24. Original Spanish definitions remain authoritative. Before an English-only collaborator designs an authorized scientific protocol, produce an explicitly versioned English reading copy of the selected candidate definitions, H-00–H-24 and relevant null/refutation conditions. Link each passage to its original source revision; review scientific equivalence separately from prose quality.
2. Translate the current Phase II selection/dependency summary and operative methodological rules only if needed for that collaboration. Preserve historical Spanish files and distinguish current decisions from superseded dated entries.
3. Translate individual evidence fiches only when they are directly needed by an admitted experiment or review. Do not translate all 53 studies, rewrite the research corpus or reopen literature searches as a prerequisite for technical Phase III closure.

No historical translation is claimed complete by this policy. Existing English architecture summaries are technical summaries, not substitutes for the Spanish scientific archive. Translation work requires no change to hypothesis numbering, adverse results, experimental counters or authorization boundaries.

## Política en español

La documentación técnica nueva tiene original canónico en inglés y una versión española sincronizada. Código, comentarios, símbolos y claves de contratos/API permanecen en inglés. Cada pareja indica revisión, fecha y enlace al otro idioma. Los cambios técnicos deben actualizar ambas versiones en la misma revisión o señalar expresamente la parte pendiente; una traducción obsoleta no debe declararse sincronizada.

`README.md` es la entrada inglesa y enlaza directamente las guías españolas. Se conservan el idioma y las fechas originales de las solicitudes del usuario, investigación, decisiones históricas, fuentes y registros de progreso/aceptación. Traducirlos no permite reemplazar interpretaciones, duplicar evidencia ni modificar resultados. Los títulos bibliográficos y campos legibles por máquina conservan los valores de origen.

El anexo de candidatas de IV es una ayuda de lectura del nuevo protocolo, no una traducción literal de H-00–H-24; las definiciones originales españolas siguen siendo la autoridad. El trabajo histórico pendiente queda acotado: antes de que un colaborador que solo lea inglés diseñe un protocolo científico autorizado, preparar una copia inglesa versionada de las candidatas, H-00–H-24 y sus nulas/refutaciones pertinentes, con enlaces a la revisión original y revisión de equivalencia científica. Traducir después el resumen vigente de selección/dependencias de II y reglas operativas solo si hace falta para esa colaboración. Traducir fichas individuales únicamente cuando un experimento o revisión admitidos las necesiten. No traducir todo el corpus de 53 trabajos ni reabrir búsquedas como requisito para cerrar técnicamente III.

Esta política no declara terminada ninguna traducción histórica. Los resúmenes arquitectónicos ingleses no sustituyen al archivo científico español. No cambian numeración, resultados adversos, contadores experimentales ni autorizaciones.
