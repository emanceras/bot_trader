## E4: what the boundary fixed, and what remains adverse

The prior worker reused its retained Python order object and client identity. The duplicate path reached risk denial and left the cached order DENIED/filled0 despite an earlier fill3 and position3, with USD300 reserved. These logs demonstrate an unsafe direct-resubmission path, not a universal engine defect or a promise that native submission is idempotent. The exact internal overwrite mechanism was not established by source inspection. The supervisor must enforce uniqueness rather than depend on undocumented duplicate-call behavior.

The new account-scoped boundary persists **PENDING before dispatch**, fingerprints the immutable command, suppresses an identical pending/processed request without another native call, rejects conflicting payloads, and preserves native events and final cache state. Reconstructing its journal preserves those identities and blocks replayed dispatch; this is a supervisor property. It does not restore native positions or authorize operational resumption. The fingerprint includes the original command envelope; this is not a generic transport-retry adapter.

**Observed corrected original E4:** one native submission for `shared-first`, fill3@100/fee0.60, coherent order `PARTIALLY_FILLED`/filled3/remaining3, position3, total USD699.40, free399.40 and reserved300. The second strategy is denied for insufficient free cash. The suppressed duplicate changes no observed cash/order/position snapshot. USD300 now corresponds to the open limit remainder, unlike the earlier terminal-order inconsistency.

However, the identical second snapshot produces no additional fill. The frozen requirement for total6 and two distinct equal native fills therefore **still fails**. Do not reinterpret the snapshot as new demonstrated replenishment, change the expectation or describe this as solved full E4. Native consumption/matching behavior on this sequence is observed; a general rule about snapshot replenishment is not established.

The first supervisor verification reports **27/32 checks passing, five failing**, retained verbatim. An independent, explicitly supervisor-only consolidation probe then passed **17/17** checks. ## E1 and the three uses

This was a directed source/evidence review, **not another R or E1 execution**. R demonstrates integer-time/availability/closed-bar/revision behavior in its standalone prototype. Earlier Nautilus E1 demonstrates native clock delivery of a small canary and a harness BLOCK/OBSERVE rule. Neither proves the complete production-to-engine path. In particular, production `MarketBar` uses microsecond `datetime` and lacks explicit closed/revision fields; R's integer-nanosecond path is not already integrated.

## Alternatives and decision

The existing `SyntheticSpotLedger` is an accounting reference, **not an admitted financial fallback**: technical SYNTH-USD only, one instrument, full fills, a100-fill cap, no independent fill identity or partial/reserved lifecycle. Its `ClosePriceExecution` uses an already received close as a technical assumption. A narrow financial use would require supported instruments/precision, causal executable entry, costs/capacity, atomic rejection and identities, independent multi-order cash/position reconciliation and an explicit rerun/discard or reconstruction policy. Add pending/partial machinery only if that contract needs it. LEAN's earlier boundary also lacks E1/lifecycle admission; its strict-cross assumption does not establish superiority or disqualification.

**Retain a modular candidate route:** bot_trader supplies causal normalization and identity/consolidation, a native engine supplies explicitly admitted order semantics, and a small independent Decimal oracle checks accounting. Do not select Nautilus by inertia or certify the own ledger by convenience. Resolve the narrow bar-use contract and E1 boundary before committing to a first financial runner; do not keep repairing the full E4 sequence merely to obtain a favorable result. Both authorized corrections are consumed and the dependent E4 route stops with its adverse finding. No further framework survey is justified by these results alone.
